Mangrove Atlas data

This site hosts the map tiles behind Mangrove Atlas, an open-source map of mangrove extent from 1985 to 2025 by Flora Carbon AI. The code and build pipeline are on GitHub.

What's here

  • gmw-v4112/index.json: the list of available tiles and metadata.
  • gmw-v4112/{z}/{x}/{y}.bin: 512 px Web Mercator tiles. Each pixel holds 41 bits, one per year from 1985 to 2025. The format is documented in pipeline/build_tiles.py.

Source, licence and attribution

These tiles are a format conversion of Global Mangrove Watch v4.1.12, licensed under CC BY 4.0, and are shared under the same licence. If you use them, please credit:

Bunting, P., Hilarides, L., Rosenqvist, A., Oakes, G., Castro Brandão Vaz dos Santos, P., Worthington, T., Rosenqvist, J., Zanaga, D., Van De Kerchove, R., Tadono, T., Kobayashi, K. (2026). Global Mangrove Watch: Timeseries of Mangrove Extent (Version 4.1.12). Zenodo. doi:10.5281/zenodo.21346457

Changes made: reprojected from WGS 84 to Web Mercator (about 38 m pixels at the equator), re-encoded as tiles, and zoomed-out tiles drawn with "mangrove anywhere in this block". The original data is unchanged on Zenodo.
